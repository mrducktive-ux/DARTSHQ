🎯 DARTS HQ

The all-in-one darts scoring and match management application.

DARTS HQ is a darts scoring application designed to provide players with an organised, interactive and enjoyable way to play darts.

Featuring an interactive dartboard, manual scoring, player profiles, match history, practice modes and tournament management.

✨ Features

🎯 Scoring System

* Interactive dartboard.
* Select individual board sections to register scores.
* Automatic score calculations.
* Manual score entry.
* Undo previous turns.
* Support for multiple players.
* 301, 501 and 701 game formats.
* Double-out and straight-out options.

👤 Player Management

* Create player profiles.
* Custom player names.
* Player statistics.
* Match participation records.
* Match history.

🏆 Tournament Management

* Create custom tournaments.
* Add participating players.
* Organise competitive matches.
* Track tournament progress.

🧮 Checkout Calculator

🎮 Practice Modes

🚀 Installation Instructions

Option 1: Use the hosted website

1. Open the DARTS HQ website.
2. Wait for the application to load.
3. Select a game format.
4. Add your players.
5. Start playing.

Option 2: Run locally

1. Download the repository.
2. Extract the downloaded files.
3. Open the project folder.
4. Locate index.html.
5. Open it in a modern web browser.
6. The application should load locally.

No installation programme is currently required.

💾 Data and Storage

DARTS HQ currently uses browser local storage to retain supported application information.

This means:

* Data is stored on the device and browser being used.
* Data is not automatically synchronised between devices.
* Clearing browser storage may remove saved information.
* Uninstalling or changing browsers may affect saved data.

Users should avoid clearing their browser data if they want to retain their locally stored information.
